# 一键入口、直角指引与悔棋恢复验证

日期：2026-09-15。版本：1.1（2026091504）。

## 行为

- 首页只有一个“开始”主按钮，无开关、无首页滚动；帮助与诊断放到二级页。开始后使用原生 ReplayKit 确认面板，录屏扩展固定为“棋研录屏”。系统“开始直播”仍由用户确认。
- 识别接收器和真实 PiP 显示层提前准备；录屏通知或本扩展首帧到达后登记一次悬浮启动意图，按系统就绪状态接续。帮助页不卸载显示层。
- 就绪晚到、退到后台、取消、停止后快速恢复、来源替换及旧系统回调分别处理；启动超时显示可重试状态。用户关闭浮窗后不被每帧拉起，首页明确显示“点继续指导恢复”。
- 指引棋盘、文字区域、标签和主按钮均为直角。思考时保留已确认棋盘；选子期间保留上一条走法。我方绿色箭头且直接播报着法，对方蓝色箭头不播报。iOS 自身画中画外框样式由系统控制。
- 双方悔棋需两帧稳定确认，恢复真实历史中的轮次，截断被撤销的未来，撤销原搜索、回看与语音再计算。优先保留已证明的向前循环，不把普通重复走子误作悔棋。
- 中途重新锚定时最多保存 16 段已确认历史，能够回到旧段；不拼接段间未知走子，不虚构撤回步数。未知历史仍等待可信标记。

## 自动回归

环境：Xcode 26.6，iOS 26.5 专用模拟器，Release，禁用并行测试。按本地移动回归流程在每组验收前清理模拟器日志，不清应用数据。

- 最终 XCTest：**162 项，0 失败**。覆盖识别、真实本机帧传输、最新帧调度、引擎/权重、跟踪、分析取消、图形绘制和启动状态。
- 原生按钮 7 项：原生 targets 保留、准备早于系统事件、重复更新不重复绑定、禁用、VoiceOver、准备时禁用、全屏真实安全区内 220×68 / 360×64 / 160×96 三种按钮尺寸的四角与中心命中。
- 启动状态 13 项：延迟就绪、前后台、自动 inline 接管、用户关闭、无回调超时、停止/恢复屏障、替换来源和显式重试。
- 悔棋覆盖双方、单步/多步/连续、恢复被吃子、将军相关局面、重新分支、跨段恢复、未见历史拒绝及两帧确认。另验证悔回同一 FEN 后两个旧搜索结果均不能覆盖新计算。
- Maestro：**2/2 流程通过**。首页入口与旧开关消失、帮助内容和返回、按钮点击。ReplayKit 日志确认实际执行原生 `buttonPressed:` 和 `openControlCenterSystemRecordingView`。

首次完整测试的按钮尺寸用例有 12 个断言失败：测试把整个 UIWindow 缩到按钮大小，顶部真实 62 pt 安全区扣减了内容。已改为完整屏幕窗口内设置按钮尺寸，保留真实安全区，生产按钮未因该测试改动；定向 7 项和最终完整 162 项均通过。
