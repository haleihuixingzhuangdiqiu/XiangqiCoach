# 左侧圆角衔接修正

日期：2026-09-15。版本：1.1（2026091507）。

## 修正

用户实际截图显示，左侧棋盘的内缩直角木框与系统 PiP 圆角形成白色月牙和截断边框，角落棋子的边缘也过于接近遮罩。

本次只处理圆角衔接和内容安全距离：木纹背景延伸到画布的左、上、下边界，去掉这三边的内缩直角木框，由系统对同一背景统一裁切。棋盘交叉点调整为 `(88, 62, 416, 468)`，为棋子、阴影和选中圈留出空间。右侧布局和配色沿用原样，仅把底部方向/来源标签稍向内收，避免标签贴到圆角边缘。

未修改识别、轮次、棋规、引擎或语音流程；棋盘绘制与建议箭头仍共用同一坐标变换，支持两个朝向。

## 验证

- Release 模拟器定向回归 **21 项全部通过**：原 18 项渲染与真实识别到引擎链路，加 3 项圆角回归。
- 读取 14 张真实棋子 PNG 的尺寸，检查两个朝向、90 个交叉点的完整棋子图（包括阴影）和圈选描边包围盒，全部落在 800×600、半径 150 的保守圆角安全区域内。
- 使用原网格位置作为负例，确认新回归能捕获用户截图中的裁切问题。
- 导出我方、对手、回看和旧局面的实际渲染器图，再施加保守圆角遮罩，检查边角棋子像素保持不变；视觉复核确认左侧背景衔接连续，底部标签完整。
- 半径 150 是测试采用的保守模型，**不是声称取得了 iOS 的实际圆角参数**。带遮罩图片是模拟预览，不是真机截图。
